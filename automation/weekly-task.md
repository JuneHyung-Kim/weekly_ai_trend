# Codex 주간 예약 작업 지침

이 저장소의 `AGENTS.md`를 먼저 읽고 따른다.

1. `planning/schedule.yml`에서 가장 가까운 `planned` 또는 `draft` 주차를 찾는다.
2. `planning/topics.yml`에서 대주제, 소주제, 맥락을 읽는다.
3. `planning/material-log.yml`에서 이미 사용한 자료를 확인한다.
4. 최근 1~2개월의 원문 자료를 우선 조사하고, 필요한 경우 중요한 이전 자료를 보완한다.
5. 함께 화면에 띄울 가치가 있는 사례 3개를 고른다. 서로 같은 결론을 반복하지 않도록 한다.
6. 각 사례에 담백한 제목, 2~3문장의 설명, 시각화할 수치나 흐름, 출처와 날짜를 준비한다.
7. 사실과 해석을 구분하고 공급업체 자체 수치는 그 성격을 명시한다.
8. `docs/data.js`에 새 주차를 추가하고 해당 소주제의 `weeks` 목록 및 `currentWeek`을 갱신한다.
9. 직전 주차의 `docs/weeks/<week-id>/index.html`을 같은 구조로 복사해 새 주차 경로를 만들고 `data-week-id`, 제목, 설명을 바꾼다.
10. `planning/material-log.yml`에 검토·사용 자료를 기록한다.
11. 로컬 HTTP 서버로 메인, 소주제, 새 주차 화면을 열어 데스크톱과 좁은 화면에서 확인한다.
12. 링크, 날짜, 인용 수치가 맞는지 다시 검증한다.
13. 변경 파일과 주요 출처, 확인 결과를 보고한다. 자동으로 외부에 게시하거나 메시지를 보내지 않는다.
