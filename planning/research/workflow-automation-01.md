# 업무 자동화 01 — 진행 메모 (비공개)

확인일: 2026-11-17

## 구성

- 대주제: AI Agent 및 활용
- 소주제: 업무 자동화
- 순서: Anthropic 광고 제작 → Notion 피드백 분류 → 우리 프로젝트
- 공개 화면에는 외부 사례 두 개와 `프로젝트 소개 · 별도 자료` 자리만 둔다.
- 함께 직접 AX를 만들어보는 계기를 마련하되, 참여 요청·질문·교훈을 발표 화면에 강제하지 않는다.

## 1. Anthropic — 광고 시안 제작 자동화

- 원문: https://claude.com/resources/articles/how-anthropic-uses-claude-marketing
- 발표일: 2026-01-26
- 볼 장면: Figma에서 문안 목록을 넣어 여러 광고 시안을 생성하는 플러그인 화면.
- 시연 영상: https://www.youtube.com/watch?v=Jp83_JMK74o (원문 연결. 날짜는 소개 글 기준이며 영상 게시일로 단정하지 않는다.)
- AI로 도구를 만든 부분(Figma 플러그인)과 업무 중 AI가 문안을 만드는 부분을 구분한다.
- 사람이 검토한 후 광고 문안 CSV를 업로드한다는 원문 맥락을 유지한다.
- 공급업체의 자사 활용 소개다. 절감 시간은 독립 검증이 없어 화면의 핵심 수치로 사용하지 않았다.

## 2. Notion — 피드백 분류·업무 등록 자동화

- 원문: https://www.notion.com/blog/how-notion-uses-custom-agents
- 발표일: 2026-02-24
- 볼 장면: Feedback Router의 공개 Slack 응답. 할 일 생성과 담당 팀 채널 전달이 함께 보인다.
- 공개 템플릿: https://www.notion.so/marketplace/custom-agents/feedback-router
- 문서의 피드백 영역 분류 → 할 일 생성 → 관련 채널 전달을 소개한다.
- 화면은 공식 글에 실린 동작 예시다. 운영 로그나 성능 측정 결과로 해석하지 않는다.
- 공급업체의 자사 활용 소개다. 두 외부 사례 모두 독립 연구가 아니며, 우리 환경에서 같은 효과가 난다고 주장하지 않는다.

## 3. 프로젝트 소개

페이지에는 `프로젝트 소개 · 별도 자료`만 표시한다. 발표자가 별도로 준비한 자료로 전환한다. 프로젝트 설명이나 시연 순서는 이 저장소에서 작성하지 않는다.

## 자료 선택 및 공개 범위

- 2025년 Anthropic 팀 활용 소개도 배경으로 확인했지만, 법무 안내 프로토타입은 실제 화면과 운영 설명이 부족해 제외했다.
- 이번 두 사례는 2026년 1~2월 자료다. 최신 출시 소개보다 실제 업무 흐름과 공개 시연 장면을 우선했다.
- 날짜·설명·화면 출처는 위 원문에서 확인했다. 템플릿은 JavaScript가 필요한 페이지여서 내용을 정적으로 검증하지 못했다. 발표 사실의 근거는 원문 글이다.
- 공개 `docs/`에는 회사 코드, 팀 구성, 내부 업무 내용, 로컬 경로, 프로젝트 화면을 넣지 않는다.
- 이미지 출처: Anthropic 원문의 `assets.claude.com/8fcd4943e754755157c55f1a059597756373119a.png`, Notion 원문의 `images.ctfassets.net/spoqsaf9291f/4bcaSlieEI3JphEanUl2Du/0bbd086053a9d63781409ae6f378e8d1/Frame_7713.png`.

## 확인 결과

- JavaScriptCore로 데이터와 기존·신규 회차 및 목차 렌더링을 실행해 오류 없이 HTML이 생성됨을 확인했다. 이 검사는 DOM 대역을 사용하므로 브라우저 배치 검증은 아니다.
- 로컬 페이지 링크, 캡처 파일, 주제·소주제·회차 연결을 확인했다. 로컬 HTTP 서버의 목차 응답은 200이다.
- 브라우저 도구는 Node 런타임 시작 오류로 실행되지 않았다. 데스크톱·좁은 화면의 최종 배치와 상호작용은 미확인이다.
- 두 원문 캡처를 직접 확인했고, 새 회차에서 이미지 전체가 보이도록 `object-fit: contain`을 적용했다.
